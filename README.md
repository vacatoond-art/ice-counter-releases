# ❄ Ice Counter

Программа для Windows, которая считает людей на льду по камерам **Trassir**. Её ставят на обычный компьютер в той же сети, что и сервер Trassir. Дополнительные устройства, серверы в интернете и облачные сервисы не нужны.

## ⬇️ Скачать

**[Скачать последнюю версию: IceCounterSetup.exe](https://github.com/vacatoond-art/ice-counter-releases/releases/latest/download/IceCounterSetup.exe)**

Все версии и дополнительные файлы лежат на странице **[Releases](https://github.com/vacatoond-art/ice-counter-releases/releases)**.

---

## Что умеет

- Раз в N минут (по умолчанию 10) берёт кадр с каждой камеры, находит людей нейросетью и считает только тех, кто стоит **внутри зоны льда**. Зрители у бортика и проходящие мимо в подсчёт не попадают.
- Показывает, сколько людей на льду сейчас, загрузку от лимита, график за 12 часов и кадры с камер.
- Работает в фоне со значком в трее (❄ у часов) и может запускаться вместе с Windows.
- Дашборд можно открыть с телефона или другого компьютера в той же сети, по паролю.
- Выгружает историю в CSV (открывается в Excel).

## Требования

| | |
|---|---|
| Система | Windows 10 или 11, 64-бит |
| Память | от 8 ГБ |
| Процессор | любой за последние 5–7 лет. Видеокарта не нужна |
| Сеть | компьютер в одной локальной сети с сервером Trassir |
| Компонент Windows | Microsoft Edge WebView2: в Windows 11 и обновлённой Windows 10 уже есть. Если его нет, установщик предложит поставить (нужен интернет) |

Один кадр обрабатывается за 1–5 секунд. При опросе раз в 10 минут обычный офисный компьютер спокойно справляется с 20 камерами.

## Установка

1. Скачайте `IceCounterSetup.exe` по ссылке выше.
2. Чтобы Windows не показывала синее окно SmartScreen: правой кнопкой по файлу → **Свойства** → внизу галочка **Разблокировать** → **ОК**.
   Если окно всё же появилось, нажмите **Подробнее → Выполнить в любом случае**.
3. В установщике отметьте нужное:
   - **Ярлык на рабочем столе**;
   - **Запускать вместе с Windows**: рекомендуется, чтобы подсчёт шёл без участия человека;
   - **Установить Microsoft Edge WebView2**: галочка появляется, только если этого компонента на компьютере нет. Оставьте её включённой, без WebView2 окно программы не откроется (программа тогда откроется в браузере);
   - **Доверять издателю Vacation Z**: Windows один раз попросит подтверждение администратора. После этого программа и обновления будут показывать издателя Vacation Z вместо «Неизвестный издатель». Если у вас нет прав администратора, снимите галочку: программа будет работать и без неё.
4. Нажмите **Установить**. Права администратора для самой установки не нужны: программа ставится в профиль пользователя (`%LOCALAPPDATA%\Programs\Ice Counter`).

## Подготовка Trassir (один раз)

На сервере Trassir: **Настройки сервера → Web-сервер (SDK)**:
1. Включите **SDK**.
2. Отметьте флаги **«Дерево объектов»** и **«JPEG»**.
3. Запомните порт: по умолчанию **8080**.
4. Заведите отдельного пользователя Trassir **только с правом просмотра** нужных камер. Не используйте учётную запись администратора.

## Первая настройка программы

1. При первом запуске программа откроется на вкладке **Настройки**.
2. Блок **Сервер Trassir**: IP-адрес, порт, логин, пароль. Галочка **HTTPS** обычно включена. Нажмите **Сохранить и подключиться**.
   - Программа найдёт все камеры, они появятся в блоке **Камеры**.
   - При первом подключении программа **запоминает сертификат сервера Trassir** и дальше соединяется только с ним (🔒 под формой).
3. Для каждой камеры, которая смотрит на лёд, нажмите **Зона →**:
   - программа возьмёт свежий кадр и покажет найденных людей рамками;
   - **кликайте по кадру, обводя лёд**, и перетаскивайте точки, чтобы поправить. Число «в зоне» справа меняется сразу;
   - нажмите **Сохранить зону**. Камера автоматически включится в подсчёт.
4. Блок **Подсчёт**: название объекта, как часто считать и **лимит людей**. Лимит нужен для полосы загрузки и красной линии на графике.

> Камеры с перекрывающимся обзором: обводите на каждой **свою часть льда**, без пересечений, иначе одни и те же люди посчитаются дважды.

Можно подключить камеру **без Trassir**: в блоке «Камеры» → **Добавить камеру по ссылке** → RTSP-адрес (`rtsp://логин:пароль@IP:554/...`) или ссылка на JPEG-снимок.

## Ежедневная работа

- **Дашборд**: сколько людей на льду сейчас, график, кадры с камер. Обновляется сам каждые 30 секунд. Кнопка **«Посчитать сейчас»** запускает внеочередной замер.
- **Закрытие окна** не останавливает программу, она уходит в трей. Открыть снова можно двойным щелчком по значку ❄. Полностью выключить: правой кнопкой по значку → **Выход**.
- **Доступ с телефона**: Настройки → «Доступ с других устройств» → галочка, задайте пароль → **перезапустите программу** (трей → Выход → запустить снова). Адрес: `http://IP-этого-компьютера:8765`, логин любой, пароль тот, что задали. При первом включении Windows спросит разрешение брандмауэра: разрешите для **частной** сети.
- **Компьютер должен быть включён.** Отключите сон: Параметры → Система → Питание → «Переводить в спящий режим» → **Никогда**.

## Просмотр статистики через интернет

Статистику можно смотреть с телефона из любой сети, не только по локальной сети. Для этого в программе один раз включите выгрузку:

1. Откройте **Настройки** → блок **🌐 Доступ из интернета**.
2. Поставьте галочку **«Публиковать статистику на сервер»**.
3. Укажите **название объекта**, а также **логин и пароль**, по которым будете входить на страницу статистики.
4. Нажмите **«Сохранить и проверить»** — должна появиться строка «Связь с сервером есть».

После этого откройте в браузере (с телефона или любого устройства) адрес **https://ice.dashameetme.online** и войдите заданными логином и паролем. На странице видно:

- сколько людей на льду сейчас и загрузку от лимита;
- график посещаемости с переключателем **12 часов / Сутки / Неделя** (за сутки и неделю — по часам);
- таблицу **по часам** со средним и пиковым числом людей;
- кнопку **«Выгрузить CSV»** — выгружает замеры (раз в 10 минут) в файл для Excel.

Данные обновляются после каждого замера и остаются доступны, даже если компьютер на объекте выключен. Наружу передаются только числа и график — доступа к камерам и к Trassir нет.

## Обновление и удаление

- **Обновление**: скачайте новую версию со страницы Releases и установите поверх. Настройки, зоны и история сохранятся.
- **Удаление**: Параметры → Приложения → Ice Counter → Удалить. Данные останутся в `%LOCALAPPDATA%\IceCounter`. Если они не нужны, удалите эту папку вручную.

## Возможные проблемы и решения

### Установка и запуск

| Что видно | Почему | Что делать |
|---|---|---|
| Синее окно «Система Windows защитила ваш компьютер» | SmartScreen не знает новую программу, скачанную из интернета | **Подробнее → Выполнить в любом случае**. Или до запуска: Свойства файла → **Разблокировать** |
| «Неизвестный издатель» при установке | Подпись Vacation Z ещё не добавлена в доверенные (так всегда при самом первом запуске установщика) | Оставьте галочку «Доверять издателю Vacation Z». Для всей сети см. раздел «Для IT-отдела» |
| Антивирус удалил файл или предупреждает | Антивирусы иногда подозревают программы, собранные PyInstaller, и установщики, которые добавляют сертификат | Добавьте файл в исключения или отправьте в лабораторию антивируса на проверку. Программа ничего не скачивает и не запускает из интернета |
| Окно программы не открывается, вместо него открылся браузер, или окно белое | Нет компонента WebView2: при установке сняли галочку или не было интернета | Переустановите программу с галочкой «Установить Microsoft Edge WebView2» или скачайте «WebView2 Runtime» с сайта Microsoft. Пока можно работать в браузере, подсчёт идёт как обычно |
| Запускаю ярлык, а открывается браузер | Программа уже запущена (в трее) | Так и задумано: второй экземпляр не запускается и открывает уже работающий |
| Ничего не открывается, в логе ошибка про порт 8765 | Порт занят другой программой | Закройте ту программу или напишите разработчику, чтобы сменить порт |

### Подключение к Trassir

| Сообщение | Почему | Что делать |
|---|---|---|
| «Нет связи с Trassir (IP:порт)» | Неверный IP или порт, компьютер в другой сети, Trassir выключен, мешает брандмауэр | Проверьте IP и порт SDK. Откройте в браузере `https://IP:8080/`: должна ответить страница Trassir. Проверьте, что компьютер в той же сети |
| «…по HTTPS: Connection refused» | SDK выключен или работает по HTTP | Включите SDK в Trassir. Если SDK настроен на HTTP, снимите галочку HTTPS |
| «Trassir не пустил: неверный логин/пароль или SDK выключен» | Ошибка в логине или пароле, или у пользователя нет прав | Проверьте логин и пароль, попробуйте войти ими в клиент Trassir |
| «Сертификат сервера Trassir изменился» | Trassir переустановили или обновили сертификат. **Или кто-то в сети подменяет сервер** | Если сервер действительно меняли: Настройки → **Принять новый сертификат** → «Сохранить и подключиться». Если не меняли, сначала разберитесь с администратором сети |
| «Trassir не отдал кадр» | Нет флага «JPEG» в SDK или у пользователя нет прав на камеру | Включите «JPEG» в настройках SDK, дайте пользователю права на просмотр камеры |
| После подключения нет нужных камер | У пользователя Trassir нет прав на них | Дайте права в Trassir и нажмите «Сохранить и подключиться» ещё раз: новые камеры добавятся |
| «Не удалось получить кадр по RTSP» (камера по ссылке) | Неверная ссылка, логин или пароль, камера недоступна | Проверьте ссылку в VLC: Медиа → Открыть URL |

### Подсчёт

| Что видно | Почему | Что делать |
|---|---|---|
| «Нет камер в подсчёте» | Ни у одной камеры не задана зона или не включён переключатель | Задайте зону и включите камеру в Настройках |
| Число меньше реального | Люди далеко и мелкие, загорожены друг другом, плохой свет, блики, ночь | Обведите зону так, чтобы дальний край был виден достаточно крупно. Добавьте камеру на дальнюю часть льда. Точность падает ночью и в метель |
| Число больше реального | Зона захватывает трибуны или проход. Камеры перекрываются | Поправьте зону по краю льда. Разделите зоны соседних камер |
| Число скачет между замерами | Люди двигаются, кто-то кого-то загораживает | Это нормально. Программа берёт 3 кадра подряд и записывает медиану |
| Красная плашка ошибки на карточке камеры | Последний замер этой камеры не удался | Текст ошибки на плашке, решения в таблице выше. Следующий замер попробует снова |
| График с пропусками | Компьютер спал или был выключен, программу закрывали | Отключите сон, включите автозапуск |

### Где смотреть подробности

- Лог программы: `%LOCALAPPDATA%\IceCounter\ice-counter.log` (вставьте этот путь в адресную строку Проводника). Пароли в лог не пишутся.
- Если пишете разработчику, приложите этот файл и скриншот ошибки.

## Безопасность и данные

- **В интернет программа ничего не отправляет.** Нет статистики, обновлений по сети и облачных сервисов. Нейросеть встроена и работает на процессоре. Программа соединяется только с адресами Trassir и камер, которые вы ввели сами.
- **Снаружи программа недоступна.** По умолчанию она принимает подключения только с этого компьютера (`127.0.0.1`). Доступ из локальной сети включается вручную и только с паролем. Внутри сети он идёт по обычному HTTP без шифрования, поэтому не включайте его в общедоступных сетях.
- **Пароли** (Trassir, ссылки камер, пароль доступа из сети) хранятся зашифрованными средствами Windows (DPAPI). Расшифровать их можно только под той же учётной записью Windows на этом компьютере. В логи и сообщения об ошибках пароли не попадают.
- **Подмена сервера Trassir** обнаруживается по отпечатку сертификата (см. «Сертификат сервера Trassir изменился»).
- **Кадры с людьми**: хранится только последний кадр каждой камеры, он перезаписывается при каждом замере. Архива видео нет, лица не распознаются, в истории только числа.
- Все данные лежат в `%LOCALAPPDATA%\IceCounter`: база `ice.db`, кадры `snapshots\`, лог.

## Для IT-отдела

- **Доверие к подписи на всех компьютерах**: раздайте `vacation-z-codesign.cer` (есть на странице Releases) групповой политикой в хранилища **«Доверенные корневые центры сертификации»** и **«Доверенные издатели»**. Для одного компьютера достаточно запустить `trust-certificate.ps1` от администратора. Отпечаток SHA-1 сертификата: `A5AEF51BB2912E48B877D04147E33B910CF58C1A`. Сертификат годится только для подписи программ, для сайтов его использовать нельзя.
- **SmartScreen** для скачанных файлов можно разрешить политикой по издателю или хешу файла.
- **Сеть**: программе нужен доступ к серверу Trassir по порту SDK (по умолчанию TCP 8080) или к камерам по RTSP (TCP 554). Входящие подключения не нужны, если не включён доступ с других устройств (тогда TCP 8765).
